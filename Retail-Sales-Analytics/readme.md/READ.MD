# 📊 Retail Sales Analytics Dashboard

## 📌 Project Overview

This project demonstrates an end-to-end retail sales analytics workflow using Python and Power BI. The dataset was cleaned, transformed, analyzed, and visualized to generate business insights through an interactive dashboard.

---

## 🚀 Tools & Technologies

- Python
- Pandas
- Power BI
- Excel

---

## 📂 Project Workflow

1. Data Cleaning
2. Feature Engineering
3. Exploratory Data Analysis (EDA)
4. Power BI Dashboard Development
5. Business Insights

---

## 📈 Dashboard Features

- 💰 Total Sales KPI
- 📈 Total Profit KPI
- 📦 Total Orders KPI
- 👥 Total Customers KPI
- 📊 Sales by Category
- 🌍 Sales by Region
- 🏆 Top 10 Products
- 📅 Sales Trend
- 🎛️ Interactive Slicers (Year, Region, Category)

---

## 📊 Business Insights

- Identified top-performing product categories.
- Compared sales across different regions.
- Analyzed product-wise sales performance.
- Built an interactive dashboard for business decision-making.
